Self-Hosted Font Options

The website uses the Google Fonts Latin WOFF2 distributions of these families:
Inter, Source Sans 3, Source Serif 4, and Literata. The files are served from
this site rather than requested from Google Fonts by visitors. fonts.css
declares the available normal styles and variable weight ranges.

Distribution source:
https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Literata:wght@400..700&family=Source+Sans+3:wght@400..700&family=Source+Serif+4:wght@400..700&display=swap

Font files are downloaded from the fonts.gstatic.com URLs supplied by that CSS.
Google's Latin subsets may fall back to other fonts for characters outside
their declared Unicode ranges.
